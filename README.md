# 약국회화 · Pharma Talk

한국 약사를 위한 일본어·영어 90일 회화 학습 웹 앱입니다. 휴대폰과 PC에서 이용할 수 있습니다.

## 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 http://localhost:3000 을 여세요. Codespaces에서는 포트 3000의 미리보기를 엽니다.

## 기능

- 언어별 90개 주제: 첫 만남·기본 문진 → 증상·배경 확인 → 안내·상담 마무리 (각 30일)
- 하루 10분: 발음 듣기, 따라 말하기, 상황 대화, 뜻 확인 퀴즈
- 정답 확인 후 학습 완료, 언어별 브라우저 진도 저장
- 완료 다음 날 첫 복습. 기억나면 이후 3일, 7일, 14일 간격; 어려우면 다음 날 재복습
- 브라우저 음성 합성과 지원 브라우저의 음성 입력 (인식 문장 확인 후 전송)
- API 키 없이 정해진 예시 대화, 키 설정 시 실제 AI 여행객 역할극과 한국어 번역·교정

진도는 동일 브라우저에만 저장되며 계정 동기화는 제공하지 않습니다. 음성 인식은 브라우저/운영체제에 따라 지원 여부가 다르며 HTTPS 또는 localhost와 마이크 권한이 필요합니다. 브라우저의 음성 서비스가 오디오를 처리할 수 있습니다. 앱 서버는 오디오를 저장하지 않습니다.

## AI 연결 (선택)

`.env.example`을 `.env`로 복사하고 서버에서만 값을 설정합니다.

```dotenv
OPENAI_API_KEY=발급받은_API_키
OPENAI_MODEL=gpt-4o-mini
PORT=3000
```

서버를 다시 시작하면 AI 연결 표시가 바뀝니다. 사용 가능한 모델을 `OPENAI_MODEL`로 변경할 수 있습니다. API 사용에는 별도 비용이 발생합니다. 키를 브라우저 코드나 Git에 넣지 마세요. `.env`는 Git에서 제외되어 있습니다.

[OpenAI 공식 텍스트 생성 문서](https://developers.openai.com/api/docs/guides/text)에 따라 Responses API를 호출합니다. 대화 문맥은 최근 12개 메시지를 전송하며 `store: false`를 설정합니다. 대화는 앱 서버에 영구 저장하지 않습니다. 실제 환자 정보 대신 가상의 상황으로 연습하세요.

이 서버는 개인 개발/미리보기용입니다. AI 키를 연결한 채 인터넷에 공개 운영하려면 인증 및 사용자별 사용 한도를 추가하세요. 현재는 IP당 분당 15회 제한만 제공하며 로그인은 없습니다. GitHub Pages는 정적 학습/예시 대화만 제공할 수 있고 실제 AI에는 Node 서버가 필요합니다.

90일 데이터 완전성, 복습 일정, 중복 완료, 정적 파일 접근 제한, AI 입력 검증 및 모의 API 응답 처리를 검사합니다. 실제 API 호출과 기기 마이크·음성 품질은 별도 환경에서 확인해야 합니다.

학습 문장은 언어 연습용이며 약품 추천이나 구체적 용량 안내를 포함하지 않습니다. 출시 전 일본어·영어 원어민과 약사의 표현 검토를 권장합니다. 기존 `언어학습모델` 빈 파일은 초기 자리표시자로 유지하고, 실제 코드는 `public/`와 `server.mjs`에 작성했습니다.
