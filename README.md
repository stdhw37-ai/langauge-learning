# 약국회화 · Pharma Talk

한국 약사를 위한 일본어·영어 상황별 회화 학습 웹 앱입니다. 휴대폰과 PC에서 이용할 수 있습니다.

## 하루 학습 구성

**하루 한 상황을 약 20분 동안 공부합니다.** 문장 하나를 하루치로 취급하지 않습니다.

1. **필수 표현 6개 (8분)**: 한국어 뜻, 일본어, 일본어의 한글 발음, 영어, 영어의 한글 발음을 함께 표시합니다. 두 언어의 듣기 버튼을 각각 제공합니다.
2. **예시 대화 6턴 (7분)**: 배운 표현을 연결해 내 역할과 상대 역할로 번갈아 말합니다. 역할을 바꾸어 연습하는 미션도 제공합니다.
3. **표현별 퀴즈 6개 (5분)**: 선택한 언어의 여섯 문제를 모두 맞혀야 해당 언어의 상황 학습을 완료할 수 있습니다.
4. **복습**: 완료한 상황의 표현 6개를 각각 복습합니다. 기억나는 표현과 어려운 표현의 다음 복습일이 따로 정해집니다.

상단의 ‘퀴즈·대화 언어’는 퀴즈, 역할 대화, 진도에 적용됩니다. 필수 표현과 예시 대화에서는 선택과 관계없이 **일본어와 영어가 모두 보입니다.** 한글 발음은 근사 표기이므로 실제 듣기와 함께 이용하세요.

## 90일 구성

30가지 상황 유형을 3회에 걸쳐 장소·물품·요청 내용을 바꾸어 익히는 **90개 수업**입니다. 각 수업에 표현 6개가 있고, 기본 표현은 다른 상황에서도 반복됩니다. 540개의 모두 다른 문장이라는 의미는 아닙니다.

- 1–30일: 기본 상황 익히기 — 발음과 뜻을 보며 대화합니다.
- 31–60일: 대상 바꾸어 확장하기 — 익숙한 문형에 새 장소·제품·요청을 넣습니다.
- 61–90일: 실전에 적용하기 — 대본을 보지 않고 말하고, 상대 역할까지 바꿉니다.

예시:

- 1일: 기차역 길 묻기 — 목적지, 직진, 우회전, 도보 시간 묻고 답하기
- 2일: 약국에서 반창고 찾기 — 물품 요청, 진열 위치, 작은 포장, 수량 확인
- 4일: 공항행 지하철 — 열차, 승강장, 환승, 표 구매
- 11일: 기침 증상 듣기 — 방문 목적, 시작 시점, 다른 증상 확인
- 31일: 우체국 길 묻기 — 이전에 익힌 길 안내 문형을 다른 목적지에 적용

데이터는 `public/curriculum.js`에 있으며, 각 상황의 6개 대화 표현과 3가지 적용 대상을 관리합니다. 각 표현에는 두 언어와 두 종류의 한글 발음, 화자 역할이 있습니다.

## 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 http://localhost:3000 을 여세요. Codespaces에서는 포트 3000 미리보기를 엽니다.

## 진도와 복습

- 진도는 언어별로 이 브라우저에 저장됩니다. 계정·기기 간 동기화는 없습니다.
- 완료 다음 날 첫 복습. 기억나면 이후 3일, 7일, 14일 간격, 어려우면 다음 날 다시 복습합니다.
- 복습 일정은 표현별로 저장하므로 한 표현을 복습해도 다른 다섯 표현은 그대로 남습니다.
- 예전 한 문장 과정의 `pharma-talk-v1` 기록은 삭제하지 않습니다. 상황별 과정은 `pharma-talk-situations-v2`에 별도로 저장합니다. 수업 내용이 달라 이전 완료 상태를 새 과정으로 자동 이전하지 않습니다.

## 음성과 AI 역할 대화

브라우저 음성 합성으로 두 언어를 듣고, 지원 브라우저에서는 마이크로 입력할 수 있습니다. 인식된 문장을 확인한 뒤 보내세요. 음성 인식은 HTTPS 또는 localhost, 마이크 권한이 필요하며 브라우저·운영체제에 따라 지원 여부가 다릅니다. 브라우저의 음성 서비스가 오디오를 처리할 수 있고 앱 서버는 오디오를 저장하지 않습니다.

API 키가 없으면 ‘예시 대본’ 모드입니다. 입력에 맞춘 AI 평가를 하는 것이 아니라, 대본의 다음 상대 응답을 두 언어와 한글 발음으로 보여 줍니다. 3번 보내면 6턴 대화가 끝납니다.

API 키를 설정하면 실제 AI가 선택한 상황의 상대 역할을 맡습니다. 길 묻기는 현지인, 약국 물품 찾기는 손님 등으로 역할이 바뀝니다. 답변에는 한국어 뜻과 두 언어의 한글 발음을 요청하며 필요할 때 짧은 표현 교정을 제공합니다. AI가 생성하는 번역·발음 품질은 실제 API로 별도 확인해야 합니다.

`.env.example`을 `.env`로 복사하고 서버에서만 값을 설정합니다.

```dotenv
OPENAI_API_KEY=발급받은_API_키
OPENAI_MODEL=gpt-4o-mini
PORT=3000
```

서버를 다시 시작하면 AI 연결 표시가 바뀝니다. 이용 가능한 모델을 `OPENAI_MODEL`로 변경할 수 있습니다. API 사용에는 별도 비용이 발생합니다. 키를 브라우저 코드나 Git에 넣지 마세요. `.env`는 Git에서 제외되어 있습니다.

[OpenAI 공식 텍스트 생성 문서](https://developers.openai.com/api/docs/guides/text)에 따라 Responses API를 호출합니다. 최근 12개 메시지를 전송하고 `store: false`를 설정하며, 대화는 앱 서버에 영구 저장하지 않습니다. 실제 환자 정보 대신 가상의 상황으로 연습하세요.

현재 서버는 개인 개발·미리보기용이며 IP당 분당 15회 요청 제한을 제공합니다. AI 키를 연결한 채 공개 운영하려면 로그인 및 사용자별 한도를 추가해야 합니다. 실제 AI 기능에는 Node 서버가 필요합니다.

## 검증

```sh
npm test
```

90일·540개 카드 구조, 두 언어와 한글 발음 누락, 6턴 역할 연결, 상황 완료 시 6개 복습 등록, 표현별 독립 일정, 이전 과정과 새 과정의 진도 분리, 서버 입력 검증 및 모의 AI 응답을 검사합니다. 실제 마이크·음성과 유료 AI 호출은 기기 및 API 설정 후 확인해야 합니다.

학습 문장은 언어 연습용이며 약품 추천이나 구체적 용량 안내를 포함하지 않습니다. 원어민과 약사의 표현 검토를 거쳐 학습 콘텐츠를 다듬을 수 있습니다. 기존 `언어학습모델` 빈 파일은 초기 자리표시자로 유지하며 실제 앱은 `public/`와 `server.mjs`에 있습니다.
